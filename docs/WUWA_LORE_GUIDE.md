## 一、剧情速查

### 1.1 结论先行（300 字）

《鸣潮》是后启示录开放世界游戏：数十年前"悲鸣"(Lament)毁灭前文明，失忆的主角"漂泊者"(Rover)
在索拉里斯(Solaris-3)苏醒，能直接吸收声骸。他周游各国——瑝珑今州(1.0-1.3)、黎那汐塔拉古那与
七丘(2.0-2.8)、拉海洛(3.0-3.3)——与守护文明的"岁主"(Sentinel)联手，对抗渴望悲鸣、以"黑潮"
(Dark Tide)收割文明的"鸣式"(Threnodian)，并追查身世：他曾是黑海岸管理者，真实身份与"路标"
计划有关。3.0 起拉海洛篇：该地区因鸣式"阿列夫一"冰封，漂泊者入星炬学院，结识爱弥斯——实为
逆转时间、自我牺牲把阿列夫一封印于"斯特赖德之门"(隧门)后的电子幽灵；3.3"昨夜群星"中他驾驶
巨型机械"隧者"(升格岁主)突入虚质空间，在全体拉海洛人协力下击败阿列夫一、接回爱弥斯。
3.5 开启第四章"梦州"篇。主题：不是英雄拯救世界，而是世界拯救英雄。

### 1.2 主线时间线（按版本）

#### 序章+第一章·瑝珑「但觉今州胜旧州」(1.0-1.3)
- 序章"万象新声"：漂泊者在今州被秧秧、炽霞唤醒，失忆，可肉身吸收声骸。
- 第一至六幕：应令尹今汐之邀，历三信物（华胥研究院/夜归军伏波营地/祈池村无音区），遇残星会
  会监"伤痕"；结识黑海岸客卿秋水、安可，调查稷廷遗址；今州遭残象潮，与忌炎用裂解炮"凿空"
  击破鸣式残象"无妄者"，吸收其湮灭之力救下今州；小家伙"阿布"与漂泊者融合。
- 1.1"往岁乘霄醒惊蛰"：乘霄山时流失控，今汐拒绝岁主"角"自我牺牲，获时序之能完成命定一战。
- 1.3"行至海岸尽头"：黑海岸泰缇斯系统被污染，守岸人揭示漂泊者曾是黑海岸管理者，
  他以人之意志校正泰缇斯。

#### 第二章·黎那汐塔「致缄默以欢歌」(2.0-2.8)
- 2.0：为阿布频率衰减赴黎那汐塔，海遇"溯海之鲸"，被愚人剧团布兰特所救；入声骸之城拉古那，
  结识教士菲比、莫塔里家珂莱塔；发现"黎那汐塔有两位神明"之秘；弗洛洛暗中关注。
- 2.2"圣者，忤逆者，告死者"：圣女卡提希娅是鸣式利维亚坦创造的生命，翡萨烈家主坎特蕾拉助其
  新生；岁主英白拉多临终还原历史真相。
- 2.3-2.4：七丘篇——角斗士露帕；"燃烧的心"：露帕对决寄宿鸣式的蜜芽与"海之女"，夺回七丘和平；
  "捕梦于神秘园中"：弗洛洛身世（村庄毁于悲鸣、半残象化），芬莱克封住巡游天国入口，鸣式宝石
  被残星会夺走。
- 2.5-2.6：总督奥古斯塔、尤诺；狩原猎杀黑潮实体"伪作的神王"、回收英白拉多旧物；
  "今夜，注定属于月亮"：众人遗忘尤诺，漂泊者入"混沌之间"将其锚定。
- 2.7 终幕"暗潮将映的黎明"：拉古那遭黑潮，阿维狄亚吸黑潮牺牲；漂泊者被腐蚀为"利维亚坦代行者"，
  与猎魔人嘉贝莉娜入七丘决战，合力击败被宝石复活的鸣式；间章"独在异乡为异客"：明庭仇远携
  始源圣器驰援。
- 2.8：黑海岸泰缇斯捕捉异常频率、裂隙展开；间章"星光流转"：千咲（穗波市），得知自己曾是
  星炬学院学生。

#### 第三章·拉海洛「驶向尚未点亮之星」(3.0-3.3)
- 3.0：入拉海洛（原非极地，因阿列夫一与隧者降临成冰封极地、虚质磁暴频发），学生琳奈引入
  星炬学院，教授莫宁筹备"换日仪式"；残星会蛊惑罗伊族致炉芯坠落，莫宁只身入炉芯，人工太阳
  "赫利俄斯"升空；序幕粉发少女爱弥斯救下漂泊者。
- 3.1"远航星"：爱弥斯是仅漂泊者可见的电子幽灵，曾为护拉海洛与隧者超频共鸣而死；机兵辛吉勒姆
  （隧者零件被虚质污染）夺取隧者炉芯；天槎空间站（稷廷研"天空海液滴"与"隧门"）。终局：
  爱弥斯逆转时间回到"隧者 vs 阿列夫一"初战之日，以身为祭把鸣式封印于隧门后——3.0"初遇"
  实为永别。
- 3.2「影下不落的黄金」（版本名"于影中启明的决心"）：为穿越隧门救爱弥斯筹备，涉及学院暗面与
  金库/炉芯线索，西格莉卡登场；幕间"明日摇曳的绯影"：灼樱巫女绯雪登场。
- 3.3「昨夜群星」（自星海尽处回响·二周年）：幕间"愿系铃中"——绯雪与姐姐玉露、苇原诅咒
  （灼樱巫女透支未来）；主线——被虚质磁暴吞没的无名者以坐标铺路，星炬学院师生与深空联合
  协力重启隧者；漂泊者驾驶隧者（升格岁主）突入虚质空间，击败鸣式阿列夫一，接回爱弥斯。
- 3.4：【推断】幕间/间章过渡版本。

#### 第四章·梦州(3.5)
「新生之作，将涌于渊」：新地区玄方地界（梦州），SP 秧秧·玄翎、穗穗登场，任务"山雨欲来风满楼"
"玄翎振壑定澜音"。

### 2.3 别名 / 旧译名 / ASR 易错点

- **达妮娅 Denia（데니아）**：韩语 ASR 常听成 **데미야 / 데니야 / 데니어**——统一译为 达妮娅。英文官方拼写是 **Denia**（不是 Dania）。
- **卡提希娅 Cartethyia（카르티시아）**：早期泄露名/旧译"**卡提亚**"；ASR 易错 **카르테시아/카르테지아**。
- **夏空 Ciaccona（샤콘）**：英文官方是 **Ciaccona**（不是 Chaconne）；韩语常误读 샤코누。
- **洛可可 Roccia（로코코）**：英文官方是 **Roccia**（不是 Rococo）。
- **爱弥斯 Aemeath（에이메스）**：英文官方 **Aemeath**（不是 Aimes）。ASR 易错 **게이드 / 에메스**（音频实证 2026-08-06）。
- **隧者 / 隧门**：曾译"**外域行者 / 斯特赖德**"；官方中文 = 隧者、隧门（"隧者之门"→隧门）。
- **拉海洛**：地区名（3.0），非角色；旧译"**拉哈因罗**"；英文 Lahainero（宣传亦作 Lahai-Roi）；韩文 라하이로이（另有 라하이네로 变体）。
- **漂泊者**：韩语官方 **방랑자**；不要音译"로버"。
- **千咲**：全名 **朽叶千咲**（쿠치바 치사），勿只写 치사。
- **珂莱塔 / 坎特蕾拉**：全名含姓氏（珂莱塔·莫塔里 / 坎特蕾拉·翡萨烈），ASR 易错 카롯타 / 칸타레라。
- **忌炎 Jiyan（기염）**：勿按拼音 지옌；**鉴心（감심）** 勿与 겐신(原神) 混淆；**今汐（금희）** 勿按汉字词读 금석；**白芷（설지）** 官方用 설지，非 백지。
- **秋水 Aalto（알토）**：勿音译 아알토；**卡卡罗 Calcharo（카카루）** 韩语是 카카루 不是 카카로。
- **椿 Camellya（카멜리아）**：勿用日文名 츠바키 直译。
- **莫宁 Mornye（모니에）**：勿按英文"Morning"译 모닝。
- **嘉贝莉娜 Galbrena（갈브레나）**：ASR 易错 가브리엘라。
- **弗洛洛 Phrolova（플로로）**：ASR 易错 프로로바 / 프롤로바。
- **罗伊（族/冰原）**：韩语 로야（로야족 / 로야 빙원）；音频中"로야의 룬"（罗伊的符文）曾被 ASR 粘连成"로얄론"→误译"罗雅伦"（音频实证 2026-08-06，已入 asr_corrections）。
