GOOD TO KNOW

开始前，需要知道这些

把限制说清楚，比只说“AI 很强”更重要。

视频和 API Key 会上传到项目服务器吗？

不会。工作台运行在你的 Windows 电脑上；字幕内容只会发送到你自己配置的模型接口。

必须使用昂贵模型吗？

不必须。Round 1 和 Round 2 可以分别选择模型，预算优先时可以全部使用 Flash。

现在支持哪些语言？

翻译核心现支持英语、日语和韩语转简体中文；韩语工作台入口将在后续界面更新中开放。

Whisper 是必须的吗？

不是。自适应模式会先检查 YouTube 英文字幕，质量不足时才运行完整 Whisper。
